# Why we use zod?
Main line -> Zod is a runtime schema validation library for JavaScript/TypeScript.
1. Zod validates incoming data against rules you define.
2. It reduces manual if/else validation and gives clear errors automatically.
3. It keeps validation rules organized and consistent across your backend.\

# Why we are using node js and express here?

1. Node.js -> It gives us the runtime to execute javascript on the srever
2. Express.js -> Gives the convinent framework for building the HTTP server, routes, middleware, request handling and APIs.
